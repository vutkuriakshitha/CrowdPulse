# CrowdPulse — Demo Checklist (Level A)

Use this before every panel rehearsal.

## Pre-demo (5 min before)
- [ ] Backend running on http://localhost:8000
- [ ] Frontend running on http://localhost:3000
- [ ] `/health` returns OK
- [ ] Sample CCTV video ready (sparse / dense)
- [ ] Browser zoom set for projector

## Demo flow (8–10 min)
- [ ] 1. Open CrowdPulse dashboard
- [ ] 2. Show venue twin (zones A/B/C/D)
- [ ] 3. Run / show CCTV processing result
- [ ] 4. Point to risk colors (G/Y/O/R)
- [ ] 5. Open explainable alert (why risk is high)
- [ ] 6. Show Gradient Boosting recommendations + confidence
- [ ] 7. Accept one action
- [ ] 8. Run what-if (close one exit)
- [ ] 9. Generate incident report
- [ ] 10. End with unique features summary

## Backup plan
- [ ] Precomputed dense-clip result available
- [ ] Screen recording of successful run saved

## Viva quick points
- [ ] Unique: risk + explain + decide (not only counting)
- [ ] Recommendation ML: Gradient Boosting
- [ ] Detection: YOLO
- [ ] Dataset: public for YOLO, synthetic labeled scenarios for recommender
- [ ] Level A done now; Level B pilot features next
