# CrowdPulse — Production Product Principles

This project is a **real-world production-oriented product**, delivered in phases (Level A demo → Level B pilot → Level C multi-venue).

## Build standard
- Clean Architecture
- Typed APIs + validation
- Env-based config (no secrets in code)
- Graceful failure handling
- Docker-ready services
- Schema-backed data model
- Ops-grade dashboard UX
- Scalable module boundaries

## Phased delivery (same product)
1. **Level A** — end-to-end CCTV pipeline working
2. **Level B** — pilot-ready operator workflows / multi-feed
3. **Level C** — hardened multi-venue production

Never treat Level A as disposable prototype code.
